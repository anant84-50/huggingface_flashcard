# Hugging Face Flashcard Generator

A Python-based flashcard generator using Hugging Face InferenceClient.

## Features

- Generate flashcards using an AI model
- Uses Hugging Face Inference API
- Easy to run with Python
- Compare different AI models

## Technologies Used

- Python
- Hugging Face
- Hugging Face InferenceClient
